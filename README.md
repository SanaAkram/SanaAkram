## 🚀 SaaS Products

Live, multi-tenant products I've built and shipped end to end — not tutorials, not demos.

### 🎙️ CallWala — AI Voice Calling Platform for Lead Follow-Up
Multi-tenant SaaS that automatically calls back inbound leads within ~60 seconds of form submission — **98% call connection rate**. Bilingual (Urdu + English) real-time conversational AI voice agents, an embeddable lead-capture widget, automated transcript/recording/outcome logging with an analytics dashboard, and serverless multi-tenant infrastructure with tenant isolation + tiered usage-based billing.
`Next.js · TypeScript · Python · LiveKit · OpenAI · AWS (Lambda, DynamoDB, S3)`

### 🧑‍💼 [Recruit-AI](https://github.com/SanaAkram/Recruit-AI) — End-to-End AI Recruiting Platform
Multi-tenant recruiting SaaS automating the full hiring funnel — resume intake through AI-conducted phone interviews. GPT-4o-powered resume parsing, a transparent 100-point candidate scoring engine (skills, experience, GitHub activity, culture fit), automated candidate routing + interview self-scheduling, and fraud / AI-generated-answer detection before human review. Deployed on serverless AWS via SST with multi-tenant auth & access control.
`Next.js 16 · TypeScript · DynamoDB · NextAuth · OpenAI (GPT-4o) · AWS (SST, Lambda)`

### 📬 InboxPilot — AI Email Workflow Automation
Full-stack AI platform connecting to Gmail via OAuth that classifies incoming email with LLMs, extracts actionable tasks, and generates automated daily briefings. FastAPI/PostgreSQL backend, Next.js dashboard with real-time analytics, containerized with Docker.
`Python · FastAPI · Next.js · TypeScript · PostgreSQL · Docker · Google OAuth`
